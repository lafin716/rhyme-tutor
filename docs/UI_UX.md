# UI / UX — 화면, 흐름, 디자인 원칙

> 상태 표기: **Implemented (1차 MVP)** · **Planned (2차 / 3차)** · **Deferred**
> 라우트 원천: ARCHITECTURE의 renderer 라우트 절. UI 언어는 **한국어**(AGENTS.md).

## 1. 원칙

| 원칙 | 내용 |
|---|---|
| 한국어 우선 | 모든 사용자 노출 문자열은 한국어. 영어 전용 기술 용어는 괄호로 병기 가능 |
| 정직한 상태 | 동작하지 않는 버튼, 더미 메뉴, "준비 중" 빈 화면을 1차에 두지 않는다 |
| 선생님 중심 | 주제 카드와 교실이 중심. 설정과 연결은 보조 |
| 사람 말로 된 오류 | 오류 코드 대신 행동 안내 문장 |
| 접근성 | 키보드 조작, 포커스 표시, 색 외 정보(아이콘·텍스트) 병행 |
| 테마 | 시스템 / 라이트 / 다크 (1차). 대비 기준 WCAG AA |
| 모션 | 과한 애니메이션 금지. `prefers-reduced-motion` 준수 |

## 3. 주요 흐름

### 3.1 첫 실행
```
온보딩 (5문항) → 대시보드(빈 상태) → AI 연결 확인 → 새 주제
```
- AI 연결이 안 되어 있어도 온보딩과 주제 입력까지는 진행 가능.
- 커리큘럼 생성 시점에 연결 문제가 있으면 주제 카드에 오류와 조치 안내를 표시한다.

### 3.2 새 주제
1. 폼 입력: 주제명(≤60자), 원문 요청(2–500자), 목표(≤300자), 수준, 페이스, 선생님 프리셋(4종 카드), 선생님 이름(선택, ≤20자).
2. "선생님과 시작하기" → 생성 (멱등). 주제 카드가 바로 생기고 커리큘럼 진행 상태가 표시된다.
3. 커리큘럼이 준비되면 "교실에 들어가기" 활성화.

### 3.3 교실
- 상단: 선생님 카드(아바타, 이름, 한 줄 소개), 현재 단원 제목, 진도 막대.
- 중앙: 채팅 스레드. 튜터 메시지는 Markdown 렌더링(`react-markdown` + `remark-gfm`). 스트리밍 중에는 커서 표시.
- 하단: 입력창, 전송, 응답 중이면 "중단" 버튼. 응답 중에는 전송 비활성 + 안내 문구.
- 우측 패널(넓은 화면) 또는 탭: 단원 목록, 목표 체크 상태, 퀴즈 시작.
- 실패한 튜터 메시지: "다시 시도" 버튼 (같은 행 재시도).

### 3.4 퀴즈
- 문항 수는 생성 결과를 따른다 (교사 지시 3–5문항). 한 번에 한 문항씩. 선택 후 "정답 확인" → 정답·해설 표시 → 다음 문항.
- 결과 요약 화면: 정답 수, 연결된 목표 변화(달성 / 복습 추천).
- 신고 버튼(문항별): 사유 입력 후 제출.

### 3.5 설정
| 항목 | 내용 |
|---|---|
| AI 연결 | Claude Code / Codex / Mock 상태, 기본 Provider, "다시 확인" |
| 요청 제한 시간 | 30–900초 슬라이더 또는 숫자 입력 (기본 180) |
| 학습 성향 | 설문 다시 하기 (기존 주제는 변경되지 않음을 안내) |
| 테마 | 시스템 / 라이트 / 다크 |
| 데이터 | 데이터 폴더 열기, JSON 내보내기 |
| 주제 삭제 | 주제 상세에서 진입. 확인 대화상자, 되돌릴 수 없음 명시 |

### 3.6 대시보드
- 주제 카드: 제목, 선생님 이름, 진도 %, 최근 학습 시각, 상태 배지(준비 중 / 학습 가능 / 실패).
- 카드의 "이어서 수업하기" (`data-testid="course-open"`): 해당 주제의 교실로 이동한다. 교실의 `chat-start-lesson` 버튼 라벨도 "이어서 수업하기"이며 E2E(`tests/e2e/d-classroom.spec.ts:37`)에서 검증된다 (Verified E2E).
- 빈 상태: 짧은 안내와 "첫 주제 만들기" 버튼 (더미 콘텐츠 없음).

## 4. 상태 표시 규칙

| 상태 | 표시 |
|---|---|
| 커리큘럼 생성 중 | 스피너 + "커리큘럼을 만들고 있어요" |
| 커리큘럼 실패 | 경고 아이콘 + 사유 + "다시 만들기" |
| 목표 `needs_review` | "복습 추천" 칩 (실패로 보이지 않게) |
| 목표 `achieved` (self_report) | 체크 + "스스로 표시" 보조 텍스트 |
| 메시지 `cancelled` | "중단됨" 회색 라벨 |
| 메시지 `error` | 오류 문장 + 재시도 |

## 5. 오류 문구 예시

| 코드 | 문구 |
|---|---|
| `PROVIDER_NOT_INSTALLED` | Claude Code가 설치되어 있지 않아요. 설치 후 "다시 확인"을 눌러 주세요. |
| `PROVIDER_AUTH_REQUIRED` | 로그인이 필요해요. 터미널에서 로그인한 뒤 다시 시도해 주세요. |
| `PROVIDER_RATE_LIMITED` | 사용량 제한에 걸렸어요. 잠시 후 다시 시도하거나 다른 AI를 선택해 주세요. |
| `PROVIDER_TIMEOUT` | 응답이 너무 오래 걸렸어요. 다시 시도해 주세요. |
| `BUSY` | 선생님이 아직 답변하고 있어요. 끝난 뒤에 보내 주세요. |
| `COURSE_IMMUTABLE` | 주제 이름과 원문은 바꿀 수 없어요. (문구 예시만. `learning/service.ts`에는 이 코드가 없고, 제목·원문은 수정 스키마에서 제외되어 있다. 발생 경로 미확인) |

## 7. 빈 상태와 로딩

- 빈 상태는 다음 행동 하나만 제안한다.
- 로딩은 500ms 이상일 때만 표시해 깜빡임을 줄인다.
- 목록은 메시지 페이지(최신 50개, `CLASSROOM_MESSAGE_PAGE`) 단위로 불러오고 위로 스크롤하면 이전 페이지를 가져온다. 스크롤 동작은 Unverified.

## 8. 내보내기 화면

- 설정 → 데이터 → "JSON 내보내기": 네이티브 저장 대화상자 (main 프로세스). **Unverified**: 화면에서 끝까지 실행한 기록이 없다.
- 파일에는 주제, 커리큘럼, 메시지, 퀴즈 기록, 기억이 들어간다. API 키와 CLI 자격 증명은 포함하지 않는다.
- 포맷 버전 필드를 포함한다. 가져오기는 Deferred.
